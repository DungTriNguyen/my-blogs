# Compare FlashList vs FlatList vs ScrollView
 
> FlashList, FlatList, and ScrollView are commonly used libraries for rendering lists in the UI. Since each library has different use cases and performance characteristics, developers should select the most suitable option to ensure optimal performance and a better user experience.


## FlashList

document origin: https://shopify.github.io/flash-list/

install:

```md     
    Expo: npx expo install @shopify/flash-list expo-dev-client
    React Native: yarn add @shopify/flash-list
```

Usage: 

```md
    import { FlashList } from @shopify/flash-list
```


## FlatList

document origin: https://reactnative.dev/docs/flatlist

Usage:

```md     
    import { Flatlist } from 'react native'
```



## ScrollView

document origin: https://reactnative.dev/docs/scrollview

Usage:

```md     
    import { ScrollView } from 'react native'
```
